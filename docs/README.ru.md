# BotW Unexplored

BotW Unexplored — homebrew-приложение Nintendo Switch с интерактивной картой для *The Legend of Zelda: Breath of the Wild*. Оно читает локальное сохранение выбранного профиля или резервную копию сохранения, когда BotW запущена, и показывает прогресс поиска объектов прямо на консоли.

Текущая версия форка — **v2.2.5**. Английская документация: [README](../README.md).

## Возможности

- Интерфейс на English, Русском и Español; русские названия локаций и подсказки короков основаны на локализации Switch-версии игры.
- Короки, святилища, DLC-святилища, локации, хиноксы, глыбники и молдоры.
- Обычный режим и Master Mode.
- Режимы отображения «Не найдено», «Найдено» и «Все».
- Ручная отметка любых поддерживаемых объектов при работе с backup, раздельно по профилю и игровому режиму. Сохранение BotW никогда не изменяется.
- Карточка ObjectInfo для всех объектов, кроме короков; у корока открывается полная подсказка с изображением и маршрутом.

## Установка

1. Скачайте `botw-unexplored.nro` со страницы [Releases](https://github.com/sklart/botw-unexplored/releases).
2. Скопируйте его в `sdmc:/switch/botw-unexplored/botw-unexplored.nro`.
3. Откройте Homebrew Menu и выберите профиль с сохранением BotW.

Чтобы использовать приложение во время запущенной игры, один раз запустите его при закрытой BotW: будет создана резервная копия сохранения.

## Управление

- Левый стик или перетаскивание пальцем — перемещение карты.
- Правый стик по вертикали или `L` / `R` — масштаб.
- `X` — открыть/закрыть легенду или информационную панель.
- `Y` — Normal Mode / Master Mode, если доступен.
- `-` — другой профиль; `+` — выход.
- D-Pad — смещает cursor в пределах видимой карты.
- `ZR` — плавно перейти к ближайшему видимому не найденному объекту и поместить cursor на него.
- `A` на короке — полная подсказка корока; `A` на остальных объектах — ObjectInfo.
- `B` в ObjectInfo или подсказке корока — отметить объект найденным, только когда BotW запущена и используется backup.
- В легенде: D-Pad и `A` или touch — выбор пунктов; `ZL` — язык.

## Локализация и игровые данные

Русские названия локаций генерируются из пар официальных архивов Switch `Msg_USen.product.ssarc` и `Msg_EUru.product.ssarc`. Игровые архивы в репозиторий не включаются. Инструмент генерации и его описание находятся в [`tools`](../tools/README.md).

## Сборка и тесты

Нужны devkitPro/devkitA64 и пакеты `switch-mesa`, `switch-glad`, `switch-glm`, `switch-freetype`:

```bash
pacman -S switch-mesa switch-glad switch-glm switch-freetype
make
bash tests/run_host_tests.sh
```

GitHub Actions выполняет host-тесты, ASan/UBSan, проверку генератора локализации и Switch-сборку с публикацией `.nro` как artifact.
